# UI

Open DS components. They are shadcn-style React components on Radix and Tailwind v4.

Each component reads only component keys: CSS variables such as `--button-primary-background`. A scheme's `tokens.css` sets those keys, so each scheme restyles every component without changing its code. That is how theme overrides work here.

| Path                   | What it is                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| `src/components/*.tsx` | 14 components. Each file starts with a comment that says when to use it and which keys it reads. |
| `src/styles.css`       | Base page styles from the tokens.                                                                |
| `registry.json`        | A shadcn registry: every component, the `cn` helper, and one theme per scheme and brand.         |
| `r/*.json`             | Built registry items with file content (generated by `pnpm registry`).                           |

```bash
pnpm --dir ui test       # builds the registry, renders every component, checks every variable exists
pnpm --dir ui typecheck
```

The CLI copies these files into a project. This works the shadcn way: you own the code after it is copied.
