# The Open DS brand

Open DS has its own look, separate from the five schemes. It uses route B, "Grid".

| Role             | Value               |
| ---------------- | ------------------- |
| Paper            | `#F6F2E9`           |
| Ink              | `#16140F`           |
| Accent           | `#FF5A1F`           |
| Accent text      | `#B93A00`           |
| Line             | `#CFC6B4`           |
| Display and text | Bricolage Grotesque |
| Labels and code  | DM Mono             |

The product name is pending. It lives only in `brand.json`.
