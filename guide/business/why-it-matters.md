# Why it matters

Teams copy design systems that were made for someone else's product. The values come along; the reasons do not. When the product changes, nobody knows which value to change, so the system drifts or gets rebuilt.

AI makes this sharper. Agents now write a lot of UI. Without the reasons, an agent guesses: a new grey here, a second primary button there.

Open DS gives both people and agents the reasons, as data:

- **Faster start.** Pick a scheme that fits, deploy it in one step.
- **Explainable decisions.** Every token traces back to an answer about the product and its people.
- **Agent-ready.** Usage rules and voice are machine-readable, so agents follow the system.
- **Safe change.** Change an answer and see what moves, instead of editing values one by one.
