# The journey

1. **Pick a scheme.** Five ready-made schemes, each a full set of answers for one kind of product. Read what each is for and what to avoid it for.
2. **Deploy it.** Connect your AI and let it call `deploy`, or run `open-ds init <scheme>` yourself. Both run the same engine.
3. **Build with it.** Your agent reads `AGENTS.md` and asks `when_to_use` before it chooses a component or a token.
4. **Change what differs.** Later, change an answer. Because every token traces back to an answer, you know what moves. (Flavours: planned.)
