# Open DS: questions and options missing from Jira OD-15..OD-28

Method: I read all 113 questions in OD-15..OD-28 (14 stories, saved in `/workspace/open-ds/jira-od15-28.txt`) and compared them with `decision-matrix.md`. A row is listed only when the Jira text has no equal question. Each row has a fetched source URL. I did not create or change any Jira ticket.

**Counts:** 64 new questions or options (scheme candidates). Jira has 113; the matrix has 107 rows.

Note on Primer: the fetched page says "nine themes across two modes" but lists no theme names. I did not list colorblind variants as a fact.

## Top 5 missing questions

1. **Is contrast guaranteed by the scale itself or checked after?** (OD-27) Radix guarantees APCA Lc 60 and Lc 90 by step number; Leonardo makes contrast the input. This changes what a "calculation scheme" must say.
2. **What is in one shareable item?** (OD-28) shadcn registry item schema (files, dependencies, cssVars light/dark) is the closest model for the boilerplate format.
3. **Which choices lock after first generation?** (OD-28) shadcn locks style, baseColor and cssVariables at init. A pack needs the same rule.
4. **How is an on-color paired with its surface?** (OD-16) Four tools use four names (foreground, content, on-x, contrastText). The pack must pick one.
5. **Is a theme a set of token sets, and what are the modifiers?** (OD-25) Tokens Studio and the DTCG resolver describe themes as combinations; no Jira story covers the data model.

## Jira questions the matrix confirms (no change)

Existing Jira options match tool practice for: base unit 4 or 8 px (Carbon 8, Atlassian 8, Radix 4-based steps, MUI 8), 12-column grid (Atlassian), 3 token tiers (DTCG, Primer, Material), curly-brace references (DTCG), class or attribute theme switch (shadcn, daisyUI), 2 px focus ring (Primer).

## Gaps in my evidence

- Iconography has little data: only Carbon sizes, Radix Icons grid, Spectrum outline style. OD-24 stays mostly unverified.
- Material 3 shape-scale radius values and elevation dp values were not on fetched text.
- Huetone, Polaris docs pages, Supernova docs, Park UI color docs were JS-only and not readable.
- Open Props, Polaris, Primer, Radix values come from published CSS files (unpkg), not prose docs.
