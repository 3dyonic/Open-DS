# open-ds-mcp

MCP server for the decision dictionary. The package name is a placeholder.

The server gives rules and a checker. It runs no model. There is no `build_tokens` tool.

```bash
uv run open-ds-mcp
uv run open-ds-mcp --http
```

Tools: `list_scopes`, `get_questions`, `get_option`, `check_recipe`.
