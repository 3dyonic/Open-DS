## 3. Gaps and cautions

- Not fetchable as text (JS-only or blocked): Huetone app internals, tweakcn site, Supernova docs, Park UI color docs, Polaris design pages (the old polaris-react pages now show a generic Shopify page; values above come from the published `@shopify/polaris-tokens` CSS file on unpkg).

- Tokens Studio official MCP: still unverified in docs (Round 1 caution stays).
- Prism UI Design MCP is a small community project (lnksoul1). Use it only as an example of "generator" option sets, not as an authority.
- Radix Colors, Tailwind and Material give no public calculation for hand-tuned values on the fetched pages. Open DS should record them as "fixed palette" schemes, not as formulas.
- FlashDSM: pages and the site llms.txt are marketing and docs. Per-tier feature lists, token defaults and motion roles come from the public site JavaScript bundle, not from documentation, and may change. The generation prompt and model rules are not public.
- Iconography has thin evidence: only Carbon sizes, Radix Icons grid, Spectrum style and Primer Octicons were found.
