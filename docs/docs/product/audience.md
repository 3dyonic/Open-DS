# Audience

Open DS is for **makers, product teams and their AI**. It is not only a developer tool.

- **Makers** pick a scheme that fits their product and get a full system without designing one from zero.
- **Product teams** get decisions they can explain: every value says why.
- **AI agents** get structured context: the scheme JSON, usage rules, voice, `AGENTS.md`, a skill and an MCP server. An agent can build UI that follows the system instead of guessing.
