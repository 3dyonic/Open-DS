# Positioning

| Kind of tool                        | What it gives                 | What Open DS adds                                            |
| ----------------------------------- | ----------------------------- | ------------------------------------------------------------ |
| Component libraries (shadcn, Radix) | Accessible components you own | A scheme that themes them, with a reason for every value     |
| Token tools (Style Dictionary)      | A build from tokens to code   | The decisions behind the tokens, and which answers pull them |
| Documentation sites                 | Pages about the system        | The same content as data, readable by agents                 |

Open DS builds on these tools instead of replacing them. It uses shadcn and Radix for components and Style Dictionary for tokens.
