# Voice and tone

Open DS writes in plain, direct words. Short sentences. One idea per sentence. Simplified Technical English where it helps.

- Say what something does, then why.
- Lead with the question and the answer. Put tokens second.
- Answers are words ("fast", "compact"), never raw values. The value behind a word lives in the token reference.
- Never invent numbers, names or claims.

Each scheme has its own voice and tone for the products built with it. See the scheme pages.
